## 🧰 Toms Tools

<a href="https://github.com/tj537/toms-tools"><img src="https://raw.githubusercontent.com/tj537/toms-tools/main/docs/social-preview.png" alt="Toms Tools – 32 offline tools in one HTML file" width="640"></a>

**32 small tools in one HTML file** – PDFs, images, screenshots, mind maps, SWOT & business models, citations, flashcards and more. Runs completely offline in your browser, no install, no admin rights – made for the work PC. English & Deutsch.
